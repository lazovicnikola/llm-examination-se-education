# Replication Package: Use of Generative AI in Examination Contexts

This repository contains the anonymous replication package for the master thesis:

## *Use of Generative AI in Examination Contexts in a Swedish University*

### Author

Nikola Lazovic  
Mälardalen University  
School of Innovation, Design and Engineering  
Master of Science in Computer Science with Specialization in Software Engineering  

---

## Repository Contents

This repository contains the supplementary materials used in the thesis.

### SMS

Contains the materials related to the Systematic Mapping Study (SMS), including the search and selection process, snowballing procedure, study classification, data extraction, and analysis.

#### Files

- `systematic-mapping-study.xlsx`
- `data-extraction-analysis.xlsx`

---

### Survey

Contains the survey instruments and anonymized survey response datasets used in the empirical part of the study.

#### Files

- `student-survey-questions.pdf`
- `staff-survey-questions.pdf`
- `student-survey-responses-anonymized.xlsx`
- `staff-survey-responses-anonymized.xlsx`

---

## Data Anonymization

All empirical data included in this repository has been anonymized.

No personally identifiable information is included in the published datasets. Timestamps, optional contact information, and other identifying details were removed before publication.
